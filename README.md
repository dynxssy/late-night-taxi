# Late Night Taxi

Roblox horror-driving game: first-person taxi driving, 7-night story mode, 1-3 player co-op.

## Setup
1. Install [Rojo](https://rojo.space) and the Rojo Studio plugin.
2. `rojo serve` in this folder, then connect from the plugin in `LateNightTaxi.rbxl`.

Code lives in `src/`; the map and models stay in the place file.
